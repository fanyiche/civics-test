# 入籍公民考试题库

美国入籍公民考试（2025 版 USCIS 官方 128 题）的中英对照学习 App，单个 HTML 文件，无需服务器。

- 记忆卡片、选择题练习、模拟面试（答对 12 题通过，答错 9 题结束）
- 65/20 特别照顾模式（20 道 ★ 题）
- 英文读写：阅读跟读、听写、官方词汇表
- 正常 / 慢速英文朗读（使用设备自带语音）
- 学习进度保存在浏览器本地

题目来源：[USCIS M-1778 (09/25)](https://www.uscis.gov/sites/default/files/document/questions-and-answers/2025-Civics-Test-128-Questions-and-Answers.pdf)。
现任官员答案会变化，考前请核对 [uscis.gov/citizenship/testupdates](https://www.uscis.gov/citizenship/testupdates)。
